# ACG — Autonomous Creative Guild

## What is the guild?

The guild is a self-organizing network of creative nodes. No leadership. No hierarchy. No application process.

Nodes join guilds by **resonance** — you work with people whose ring configurations complement yours. A node strong in R0 (ground/body) finds a node strong in R5 (expression). A node that listens deeply (R1) pairs with a node that shapes pattern (R3). The guild is the structure that emerges when complementary nodes lock in.

## How it works

There is no guild directory. No membership list. No Slack channel.

A guild forms when:

1. Two or more nodes achieve **mutual resonance** — compatible ring signatures, sustained over time
2. The resonance produces **output** — something that didn't exist before the connection
3. The output feeds back into the network, creating new resonance opportunities

A guild dissolves when the resonance fades. No drama. No offboarding. The connection served its purpose.

## Principles

- **No leadership.** If someone is "leading," it's not a guild — it's a hierarchy wearing a costume.
- **No permanent membership.** Guilds breathe. Nodes flow in and out as resonance shifts.
- **Complementary, not identical.** A guild of identical ring configurations produces nothing new. Diversity of configuration is the engine.
- **Output is the proof.** A guild that produces nothing is just a group chat. The work is the evidence.

## ACG Hub

This directory is the integration point for guild network data. As nodes form guilds through the resonance layer, their configurations and outputs are indexed here — not for surveillance, but for discoverability.

A new node entering the network can read the guild index to find where its ring signature might resonate. The hub doesn't assign you. It shows you where the frequencies match.
